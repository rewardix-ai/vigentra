Single-camera viewing is HLS for the same reason.

The sandbox HLS gateway delivers a 6-second segment in 15 to 80 seconds and refuses overlapping requests, so a browser wall of fifty tiles blacks out entirely. The live wall is therefore served by an edge frame service. It decodes each feed in a bounded pool, draws the edge’s vehicle detection on every frame and, on chosen feeds, runs the full ANPR engine live. A tile is answered from memory in about two milliseconds, and holds a session only while it is on screen.

Addendum. What changed after first issue

This proposal was first issued on 14 September 2026. That day the running system grew from 30 grid cameras to a 50-camera estate, and the wall moved from refreshed stills to live frames with detection drawn on them. Pages 16, 17, 40 and 43 are revised to match.

All 50 are in service and online. The last 20 were onboarded through the Traffic Police VMS installation-request flow. The registry holds 70 cameras: 50 in service and 20 decommissioned, kept for the audit trail.

A.2 Live frames with live detection on the wall

An edge frame service decodes every feed in a bounded pool and keeps the newest frame, and a background annotator draws YOLO11n vehicle detection on it. A tile is answered from memory in about 2 ms. VMS feeds open through the VMS’s own authorised live handle. A tile holds a session only while on screen; click it for full screen, and Esc returns.

A.3 Live ANPR on chosen feeds

The full Vigentra ANPR engine runs live on chosen feeds: the Delhi test clip and grid CAM06, Madhuram Bypass Road, Bhavnagar. Each read is drawn with its confidence, and a low one is shown as low. The engines share one lock, as the GPU backend is not safe across threads, and each live reader releases its own capture. That removed two crashes found under load.

A.4 Keeping the API responsive under the wall

The snapshot route checks permission in a short database session, releases it, then fetches the frame with a pooled HTTP client. Under the full wall, API health now answers in 0.02 to 0.1 seconds, where it took 5 to 15. The open-alert badge every page polls is a count and is deliberately not audited; reading the alerts themselves still is.

A.5 Console fixes found while recording the demonstration

  • Page filters and inputs survive a reload, per tab, and never a password.
  • Enter submits the sign-in and search forms.
  • The registry opens on in-service cameras and fits the map to Gujarat.
  • The logo’s tagline is set as text, so Safari lays it out correctly.
