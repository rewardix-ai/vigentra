# ANPR extra - number-plate reading with the vendored `anpr/` engine.
#
#   pip install -r requirements.txt -r requirements-yolo.txt -r requirements-anpr.txt
#
# Plate text is personal data. Read docs/anpr.md before enabling this.
#
# Only four hard dependencies: everything else the engine touches (torch,
# ultralytics, onnxruntime, safetensors, imageio_ffmpeg, matplotlib) is
# imported inside the function that needs it, and torch/ultralytics/onnxruntime
# already come from requirements-yolo.txt in the image below this one.
#
# NOT here on purpose:
#   paddlepaddle / paddleocr - only anpr/read/awiros.py imports them, lazily,
#     as an alternative reader. The shipped reader is the ONNX CRNN, so pulling
#     ~1 GB of Paddle for a path the pipeline does not take is a poor trade.
#   anthropic - only anpr/read/claude_reader.py, lazily, for the optional
#     second opinion. Install it and set ANTHROPIC_API_KEY to use that.

# opencv-contrib, HEADLESS: the restoration stack uses dnn_superres, which
# ships only in contrib, and the slim base image has no X11 for the desktop
# build (its `import cv2` dies on libxcb).
opencv-contrib-python-headless==4.11.0.86

numpy>=1.26,<3.0
PyYAML>=6.0
# Levenshtein over plate strings, used by the track-level fusion (ROVER).
editdistance>=0.8

# The CRNN reader and the denoise/deblur stages load ONNX models through
# onnxruntime. Every import of it is inside a function, so a missing wheel
# does not fail the import sweep - it surfaces as a reader that silently
# reads nothing. It must be a declared dependency, not an implicit one.
onnxruntime>=1.20
