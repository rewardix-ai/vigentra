# ANPR extra - number-plate reading with the vendored `anpr/` engine.
#
#   pip install -r requirements.txt -r requirements-yolo.txt -r requirements-anpr.txt
#
# Plate text is personal data. Read docs/anpr.md before enabling this.
#
# OpenCV, numpy, torch and ultralytics come from requirements-yolo.txt. The
# engine calls only core OpenCV, so the headless build installed there serves.
#
# NOT here on purpose: paddlepaddle / paddleocr. Only anpr/read/awiros.py
# imports them, lazily, as an alternative reader. The shipped reader is the ONNX
# CRNN, so pulling ~1 GB of Paddle for a path the pipeline does not take is a
# poor trade.

PyYAML>=6.0
# Levenshtein over plate strings, used by the track-level fusion (ROVER).
editdistance>=0.8

# The CRNN reader and the denoise/deblur stages load ONNX models through
# onnxruntime. Every import of it is inside a function, so a missing wheel
# does not fail the import sweep - it surfaces as a reader that silently
# reads nothing. It must be a declared dependency, not an implicit one.
onnxruntime>=1.20

# ByteTrack. The ANPR engine tracks vehicles through ultralytics'
# model.track(), which imports its tracker - and that tracker's lap and
# scipy - lazily, only on the first tracked frame. The plain YOLO detector
# only ever calls predict(), so nothing else here pulls them in and their
# absence surfaces as a crash on frame 1 rather than at import.
lap>=0.5.12
scipy>=1.11
